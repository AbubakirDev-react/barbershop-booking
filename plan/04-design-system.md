# 4. Дизайн и пользовательский опыт (UX)

---

## 1. Общие принципы

Создай **оригинальный визуальный стиль** современного барбершопа.

### Не используй:

- Бездумный типичный AI-дизайн
- Случайные градиенты
- Чрезмерное количество карточек
- Ненужные анимации
- Огромные декоративные элементы
- Шаблонные интерфейсы без визуальной иерархии

---

## 2. Принципы дизайна

| Принцип | Описание |
|---------|----------|
| **Профессиональная типографика** | Читаемые шрифты, выдуманные заголовки, понятная иерархия |
| **Композиция и визуальная иерархия** | Чёткое распределение внимания |
| **Сдержанная цветовая палитра** | Минимум цветов, максимум выразительности |
| **Единые отступы, радиусы, тени, размеры** | Дизайн-система с единой сеткой |
| **Реальные фотографии** | Барбершоп, мастера, услуги — без placeholder |
| **Hover, focus, disabled, loading states** | Аккуратные состояния всех элементов |
| **Адаптивность** | Мобильные, планшеты, десктопы |
| **Доступность** | Контраст, семантика, клавиатурная навигация, ARIA-подписи |
| **Понятные ошибки форм** | Инлайн-валидация, подсказки |
| **Нет горизонтальной прокрутки на мобильных** | |

> Не копируй YCLIENTS визуально. Используй его как ориентир по **функциональности**.

---

## 3. Дизайн-система

Создай единую дизайн-систему:

- Цветовые токены (светлая/тёмная тема)
- Типографика (заголовки, основной текст, размеры)
- Spacing
- Кнопки, поля, модальные окна, уведомления, таблицы, календарь
- Состояния компонентов

### Кнопка «Записаться»

- Должна быть **заметной** на публичных страницах.
- На мобильных — может быть **закреплена внизу**, но не перекрывать контент и системные элементы.

---

## 4. Отзывы

### Если автоматическая интеграция невозможна:

- Предусмотри **ручное добавление** отзывов владельцем.
- Указывай источник и ссылку.
- Нельзя создавать отзывы для визуального заполнения блока.
