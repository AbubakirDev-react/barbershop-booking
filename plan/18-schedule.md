# 18. Расписание и правила бизнеса

---

## 1. Настройки барбершопа

| Параметр | Описание |
|----------|----------|
| Часовой пояс | TZ барбершопа |
| Рабочие часы | Общие для заведения |
| Перерывы | Внутренние перерывы у мастеров |
| Выходные | Ежегодные плановые дни |
| Отпуска | Индивидуальные для мастеров |
| Разовые изменения | Корректировка расписания |
| Мин. интервал между записями | Если нужно |
| Макс. горизонт предварительной записи | Ограничение по времени |
| Правила отмены | Минимальный срок |
| Правила переноса | Условия |
| Время на подготовку | Если требуется |

---

## 2. Правила

- ❌ Не предполагать, что все мастера работают по одинаковому расписанию
- ✅ Если владелец меняет рабочие часы — проверяй существующие записи и предупреждай о конфликтах
- ❌ Не отменяй записи автоматически без явного правила
