# 11. Панель барбера

Создай защищённую панель с понятной навигацией.

---

## 1. Основные разделы

| Раздел            | URL                          | Доступ |
|-------------------|------------------------------|--------|
| Dashboard         | `/dashboard`                 | Барбер / Владелец |
| Календарь         | `/dashboard/calendar`        | Барбер |
| Записи            | `/dashboard/appointments`    | Барбер |
| Клиенты           | `/dashboard/clients`         | Барбер |
| Услуги            | `/dashboard/services`        | Владелец |
| Категории         | `/dashboard/categories`      | Владелец |
| Мастера           | `/dashboard/masters`         | Владелец |
| Уведомления       | `/dashboard/notifications`   | Барбер |
| Аналитика         | `/dashboard/analytics`       | Владелец |
| Настройки         | `/dashboard/settings`        | Барбер / Владелец |
| Пользователи      | `/dashboard/users`           | Владелец |

---

## 2. Dashboard

Показывай:

- [ ] Записи на сегодня
- [ ] Текущая запись (если есть)
- [ ] Следующая запись
- [ ] Ожидающие подтверждения
- [ ] Свободные интервалы
- [ ] Отменённые записи
- [ ] События, требующие внимания

Если запись активна — показывай доступные действия.

❌ Не заполняй календарь искусственными записями.

---

## 3. Календарь

### Виды:

- По дню
- По неделе
- По мастерам (если несколько сотрудников)

### Действия барбера:

- [ ] Открывать запись
- [ ] Подтверждать
- [ ] Переносить
- [ ] Начинать обслуживание
- [ ] Завершать обслуживание
- [ ] Отмечать неявку
- [ ] Отменять запись
- [ ] Создавать запись вручную

Все действия проверяются по роли, доступности и бизнес-правилам.
