# 19. Уведомления и напоминания (клиенты)

---

## 1. Типы уведомлений

| Тип | Описание |
|-----|----------|
| **Внутренние** | В приложении (центр уведомлений) |
| **Внешние** | Email, Telegram, MAX (если доступно) |

---

## 2. Напоминания для записей

| Напоминание | Время отправки |
|-------------|----------------|
| За 24 часа | `created_at - 24h` |
| За 2 часа | `created_at - 2h` |

### Условия отправки:

- Только для **подходящих активных** записей
- По настройкам клиента (включены ли уведомления)
- По выбранному каналу связи

---

## 3. Архитектура каналов

Подготовь адаптеры для:

- [ ] Email
- [ ] Telegram
- [ ] MAX (если есть официальная интеграция)

> Сначала реализуй канал, для которого предоставлены credentials.  
> ❌ Не обещай поддержку MAX/Telegram до проверки API.

---

## 4. Технические требования

| Требование | Реализация |
|------------|------------|
| Фоновые задачи | Supabase Cron / Edge Functions |
| Статусы отправки | Хранить в БД |
| Идемпотентность | Защита от повторной отправки |
| Повторные попытки | При временных ошибках |
| Журналирование | Ошибок без секретов |
| Отмена устаревших | После переноса / отмены |
| Проверка статуса | Перед отправкой |
| Разделение | Транзакционные vs маркетинговые |

---

## 5. Безопасность

- ❌ Не храни секреты в frontend
- ❌ Не показывай «отправлено», если канал не настроен — покажи настройку в админке
