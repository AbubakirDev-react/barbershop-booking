# 25. SEO и публичные страницы

---

## 1. Обязательные элементы

| Элемент | Описание |
|---------|----------|
| `title`, `description` | Уникальные для каждой страницы |
| Семантический HTML | `header`, `main`, `section`, `article`, `footer` |
| Open Graph | `og:title`, `og:description`, `og:image`, `og:url` |
| Favicon | SVG/PNG, разные размеры |
| `robots.txt` | Если нужно |
| `sitemap.xml` | Если нужно |
| `canonical` URL | Для избежания дублей |
| Оптимизированные изображения | WebP, `srcset`, lazy-loading |
| Локальные данные | Schema.org `LocalBusiness` (если адрес есть) |

---

## 2. Ограничения индексации

- ❌ Не индексируй приватные профили
- ❌ Не индексируй панели управления
- ❌ Не индексируй персональные данные клиентов

---

## 3. Ошибки

- ✅ Обработка неизвестных маршрутов (404 страница)
