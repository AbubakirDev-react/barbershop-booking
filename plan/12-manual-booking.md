# 12. Ручное создание записи (барбером)

Барбер должен иметь возможность записать клиента **без регистрации**.

---

## 1. Поля записи

- [ ] Имя клиента
- [ ] Номер телефона
- [ ] Мастер
- [ ] Услуги — максимум 3
- [ ] Дата и время
- [ ] Примечание (опционально)

---

## 2. Проверки перед созданием

- [ ] Доступность выбранного слота
- [ ] Длительность услуг не превышает доступный интервал
- ❌ Если времени недостаточно — не разрешай создание

---

## 3. Уведомления для ручных записей

- ❌ Не отправляй клиентские уведомления, если:
  - Нет контакта или согласия
  - Уведомления отключены
- ❌ Само ручное создание ≠ согласие на маркетинг

---

## 4. Источник записи

Создавай запись с понятным источником:

- `manual` — созданная барбером
- `online` — созданная клиентом через сайт
