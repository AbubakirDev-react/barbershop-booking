# 16. Аналитика

Создай страницу аналитики для владельца и разрешённые представления для барберов.

---

## 1. Фильтры

| Фильтр         | Описание |
|----------------|----------|
| День / Неделя / Месяц / Год | Быстрые шаблоны |
| Произвольный диапазон | Любой период |
| Мастер | Фильтрация по сотруднику |

---

## 2. Метрики

| Метрика | Источник данных |
|---------|----------------|
| Количество завершённых записей | `appointments` со статусом `completed` |
| Выручка по завершённым записям | `appointment_items.price * quantity` |
| Средний чек | `revenue / count` |
| Популярные услуги | Сортировка по количеству выполненных услуг |
| Загруженность мастеров | Процент занятости по времени |
| Количество отмен | `appointments` со статусом `cancelled` |
| Количество неявок | `appointments` со статусом `no_show` |
| Динамика выручки | Сравнение периодов |

---

## 3. Требования

- ✅ Все показатели по **реальным данным** из БД
- ❌ Не учитывать `pending`, `cancelled`, `no_show` как выполненные
- ✅ Если запись содержит несколько услуг — **не дублировать** общую стоимость
- ✅ Учитывать часовой пояс при фильтрации по дате
- ✅ Хранить суммы с точностью до копеек (`numeric(10,2)`)
- ❌ Если данных недостаточно — показывать **корректный empty state**
