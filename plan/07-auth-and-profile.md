# 7. Авторизация и профиль клиента

---

## 1. Вход и регистрация

Используй **Clerk**.

### Необходимые страницы и состояния:

- [ ] Вход
- [ ] Регистрация
- [ ] Выход
- [ ] Восстановление доступа (по возможностям Clerk)
- [ ] Обработка ошибок
- [ ] Защищённые маршруты
- [ ] Синхронизация пользователя с профилем в базе

### Дополнительно:

- Подключай Google и другие способы входа через **поддерживаемые возможности Clerk**.
- ❌ Вход через Google ≠ согласие на рассылку.
- ❌ Не считай вход через Google/Telegram автоматическим разрешением на уведомления.

---

## 2. ProfilePage

### Поля профиля:

- [ ] Имя
- [ ] Фамилия
- [ ] Номер телефона
- [ ] Email (если доступен)
- [ ] Аватар (если загружен)

### Настройки:

- [ ] Уведомления
- [ ] Каналы связи
- [ ] Приватность
- [ ] История и предстоящие записи
- [ ] Кнопка «Выйти»
- [ ] Кнопка «Удалить аккаунт»

### Безопасность:

- Проверяй номер телефона при подтверждении личности или записи.
- ❌ Не раскрывай персональные данные другим клиентам.

---

## 3. Записи клиента

### Разделы:

- [ ] Предстоящие
- [ ] Требуют подтверждения
- [ ] Завершённые
- [ ] Отменённые
- [ ] Пропущенные

### Каждая запись открывается в подробном виде или модальном окне:

- [ ] Номер / ID записи
- [ ] Дата и время
- [ ] Мастер
- [ ] Все услуги
- [ ] Длительность
- [ ] Цена каждой услуги
- [ ] Итоговая стоимость
- [ ] Адрес
- [ ] Статус
- [ ] История изменений

### Действия (там, где разрешено):

- [ ] Перенести
- [ ] Отменить
