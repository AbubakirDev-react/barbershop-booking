# 22. Маршруты и структура приложения

---

## 1. Публичные маршруты

| Маршрут | Описание |
|---------|----------|
| `/` | Главная страница (HomePage) |
| `/about` | О барбершопе / Контакты |
| `/services` | Каталог услуг |
| `/masters` | Мастера |
| `/book` | Онлайн-запись (Booking Flow) |
| `/reviews` | Отзывы |

---

## 2. Клиентские маршруты (требуют авторизации)

| Маршрут | Описание |
|---------|----------|
| `/profile` | Профиль пользователя |
| `/profile/appointments` | Список записей |
| `/profile/appointments/:id` | Детали записи |
| `/profile/settings` | Настройки профиля |

---

## 3. Барбер / Владелец (панель управления)

| Маршрут | Описание |
|---------|----------|
| `/dashboard` | Dashboard |
| `/dashboard/calendar` | Календарь |
| `/dashboard/appointments` | Записи |
| `/dashboard/clients` | Клиенты |
| `/dashboard/services` | Услуги |
| `/dashboard/categories` | Категории |
| `/dashboard/masters` | Мастера |
| `/dashboard/analytics` | Аналитика |
| `/dashboard/notifications` | Уведомления |
| `/dashboard/settings` | Настройки |
| `/dashboard/users` | Пользователи (только владелец) |

---

## 4. Принципы

- Это **ориентир**, а не требование создавать бесполезные страницы.
- Если разделы логично объединить — делай это, сохраняя удобную навигацию.
- Все защищённые маршруты проверяют права **на сервере** и в **БД (RLS)**.
